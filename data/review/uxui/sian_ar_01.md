# 아랍어 유니버스 UX/UI 시안 01 — 시안 02(장면 컷이 주인공) + 아랍어 칸 2개 (2026-11-03)

기본 구조는 일본어앱 채택 시안 02(`~/talkverse/ja/data/review/uxui/sian_02.md|.jpg`) 그대로: 장면 컷이 주인공, 왼쪽 레일 + 두 칸, 좌 스크립트·우 컷, 하단 컨트롤, 홈 「오늘의 컷」, 「나」 탭 성과. 인물은 `CHARACTERS.md`(시트 v2). 여기에는 **아랍어라서 달라지는 것**만 적는다.

## 1. 앱 한 줄 소개와 아랍어만의 강점
- 이집트 구어(카이로 말)로 시작하는 아랍어 — 오른쪽에서 왼쪽으로 쓰는 문자, 낱말 안 위치에 따라 바뀌는 글자 모양, 세 자음 어근으로 묶이는 낱말 가족.
- 학습자가 막히는 곳: ① 글자가 이어 쓰여 낱말 경계·글자 구분이 안 보임 ② 모음 부호가 없음(한글 독음이 다리 역할) ③ 같은 어근의 낱말이 서로 다른 모양으로 흩어져 보임.

## 2. 톤 토큰

## 3. 시안 02 에서 바꾸는 것(구조는 그대로)
- **스크립트 칸의 문자 방향**: 아랍어 줄은 오른쪽 정렬·RTL, 그 아래 한글 독음·한국어 뜻은 왼쪽 정렬. 번호·화자 점·🔊 는 왼쪽 가장자리에 그대로(카드 틀은 LTR, 아랍어 글줄만 RTL).
- **말풍선**(컷 위 오버레이)도 아랍어는 RTL, 꼬리는 화자 쪽.
- **자막 칩**: 「العربية · 독음 · 한국어」 세 개. 일본어앱의 가나 칩 자리 = 「모음 부호」 칩(켜면 타슈킬을 얹어 보여 줌 — 데이터에 있을 때만, 없으면 칩 숨김).

## 4. 아랍어만의 칸 — 2개만 제안
### A. 글자 돋보기(스크립트 칸에서 낱말을 누르면 아래에서 올라오는 시트)
```
┌───────────────────────────── 낱말: بيت (베이트, 집) ─────────┐
│  글자 풀기 (오른쪽→왼쪽)                                       │
│   ت ← ي ← ب        [ب 어두형] [ي 어중형] [ت 어말형]          │
│   각 글자 4형: 독립 · 어두 · 어중 · 어말  (지금 모양에 청록 테)  │
│  🔊 낱말   🔊 글자 하나씩                                       │
│  어근: ب-ي-ت  →  [어근 가족 보기]                              │
└───────────────────────────────────────────────────────────────┘
```
- 글자 4형 표는 고정 규칙(데이터 생성 아님). 어근 줄은 어근 데이터가 생긴 뒤에만 보인다.
### B. 어근 가족(탐색 탭 → 「어근 가족」, 일본어앱 「패밀리 한자」 자리)
```
┌ 레일 ┬ 어근 목록(절벽 구간별 카드) ─────┬ 가족 지도 ─────────────────────┐
│      │ R1  ك-ت-ب  쓰기     5/7         │        كتاب 책                 │
│      │ R1  ق-ر-أ  읽기     3/4         │   مكتب 책상 ─ ك-ت-ب ─ كاتب 작가 │
│      │ R2  ع-ر-ف  알다     2/6         │        مكتبة 서점·도서관        │
│      │ ...                             │  틀(모양): فاعل = ~하는 사람     │
└──────┴─────────────────────────────────┴─────────────────────────────────┘
```
- 가운데 어근 세 자음, 둘레에 앱에 나온 낱말(이미 본 것 = 남색, 아직 = 회색). 틀(وزن) 한 줄 설명.
- 인도네시아어앱 어근 가족 구조·도구(`~/talkverse/id/docs/ROOTS.md` §4)를 아랍어용으로 옮겨 채운다 — 범위는 사용자 확인 뒤.

## 6. 성과 원칙
- 세는 것: 편 완주 · 단계 · 핵심 표현 · 익힌 글자(4형) · 어근 가족 · 커버율.
- 안 세는 것: 앱 오픈 · 연속 일수 · 포인트 · 순위.
