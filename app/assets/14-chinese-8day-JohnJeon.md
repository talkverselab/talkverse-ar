## Day 1 — 인칭 + 어기조사 (17 단어)

### 어기조사 5분 학습표

| 어기조사 | 한국어 어감 | 예 |
|---|---|---|
| 吗 | "~까?" yes/no | 你好吗? |
| 吧 | "~자, ~겠지" | 走吧! |
| 啊 | "~야!, ~네" | 好啊! |
| 呀 | (啊 변형) | 谁呀? |
| 呢 | "~는?" / "~하고 있어" | 你呢? |
| 啦 | "~네!" 가벼운 완료 | 走啦! |
| 嗯 | "응" / "음" | 嗯, 好的 |
| 嘛 | "~잖아" | 这就对了嘛 |
| 哦 | "아~" / "오~" | 哦, 知道了 |
| 哪 | "어느·어떤" | 哪个? |

### 예 다이얼로그
```
A: 你好啊!     안녕!
B: 你呢?      너는?
A: 我也好啦!   나도 좋아!
B: 嗯, 走吧!   응, 가자!
```

## Day 2 — 是·不·什么·怎么·谁

```
你是谁？         누구세요?
我是 Mark。      저는 Mark입니다
不，我不是。      아니요, 아닙니다
那是什么？       그게 뭐예요? (※ "这是什么吗?" 아님)
怎么了？         어떻게 됐어요?
```

## Day 4 — 有·在·说·去·来·走·到

```
我有时间。        시간 있어
你在哪儿？        어디 있어?
他在说话。        그가 말하고 있어
我去那儿。        내가 그쪽 갈게 (※ "我去!" 단독은 감탄·욕설로 들릴 수 있음)
我们走啦~        우리 간다~
你到哪儿了？      어디까지 왔어?
```

## Day 5 — 了 / 过 (시제 ⭐)

| 표현 | 의미 |
|---|---|
| 我去了 | 갔다 (완료) |
| 我去过 | 가본 적 있다 (경험) |
| 我吃了 | 먹었다 (지금 막) |
| 我吃过 | 먹어본 적 있다 |
| 好了 | 좋아졌다 / 됐다 |

**초급 권장**: 我已经吃了。(완료 강조) / 我吃过日本料理。(경험 강조)
※ "我已经吃过了"는 완료+경험 혼합 — 고급 표현. **초급에서는 已经+了 / 过 분리해서 먼저 익히기 권장**.

## Day 6 — 부사 就·都·很·也·还·又

```

```

## Day 7 — 능원동사

| 능원동사 | 의미 | 예 |
|---|---|---|
| 要 | ~할 것 / 필요 | 我要去 |
| 会 | ~할 줄 / ~할 것 | 我会说 |
| 想 | ~하고 싶다 | 我想吃 |
| 能 | 능력 | 我能来 |
| 可以 | 허락 | 你可以走 |
| 应该 | ~해야 | 你应该来 |

## Day 8 — 종합 + 부르기 嘿·喂·嗨

```
嘿 (Hēi) → "야!" 친한 사이/주의 끌기 (영화 多, 채팅 X)
喂 (Wèi) → "여보세요!" 전화 필수
嗨 (Hāi) → "Hi!" 캐주얼 (영어 차용)

종합:
  A: 嗨! 真的好久不见啊!
  B: 嘿! 是啊!
  A: 想喝咖啡吗?
  B: 当然啦! 我喜欢。
  A: 那走吧!
```

## 자주 헷갈리는 짝

| 짝 | 차이 |
|---|---|
| 是 / 在 | 是: 이다 / 在: 위치·진행 |
| 了 / 过 | 了: 완료 / 过: 경험 |
| 想 / 要 / 会 | 想: 욕구 / 要: 필요 / 会: 능력 |
| 嘿 / 嗨 / 喂 | 嘿: 부름 / 嗨: 인사 / 喂: 전화 |
